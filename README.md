# CLCJ 2027 告知ページ

Creative Learning Conference Japan 2027 の告知ページです。GitHub Pages で公開しています。

- **文章を直したい方** → [`index.md`](index.md) だけを編集します。手順は [編集手順書(CONTRIBUTING.md)](CONTRIBUTING.md) を見てください。
- **見た目を変えたい方** → [`_layouts/default.html`](_layouts/default.html) を編集します(HTML/CSS の知識が必要です)。

| ファイル | 役割 |
| --- | --- |
| `index.md` | ページの中身(日時・会場・趣旨の要約と全文・プログラム・PeatixのURL・動画など) |
| `_layouts/default.html` | ページのデザイン |
| `_config.yml` | サイト全体の設定(通常は触りません) |
| `CONTRIBUTING.md` | 編集手順書 |
